# 3. Unseen Data / Surprise Round folder

This folder is the graded-output bundle judges should review. It should contain the following evidence for the unseen sixth spec and the known feature set.

## Required evidence set

### A. Generated DDL for the known feature specs and the sixth spec

Place the generated schema output in:

- [surprise_round/known_specs_ddl.md](surprise_round/known_specs_ddl.md)
- [surprise_round/sixth_spec_ddl.md](surprise_round/sixth_spec_ddl.md)

### B. Analytics Agent insight report over the existing tables

Place the autonomous analytics report in:

- [surprise_round/analytics_insight_report.md](surprise_round/analytics_insight_report.md)

### C. Context layer and freshness proof

Place the before/after context changelog and the context-version summary in:

- [surprise_round/context_freshness.md](surprise_round/context_freshness.md)

### D. Sixth-spec bundle

Place the full unseen-spec output bundle in:

- [surprise_round/sixth_spec_bundle.md](surprise_round/sixth_spec_bundle.md)

## Expected contents per artifact

- DDL for each known feature spec plus the unseen spec.
- A concise product-facing insight summary generated by the Analytics Agent.
- A context diff showing what changed after a new feature table was introduced.
- The trace link or trace identifier for the unseen-spec run.

## Checklist for submission

- [ ] generated DDL exists for the five known specs
- [ ] generated DDL exists for the sixth spec
- [ ] analytics report was generated from real ClickHouse evidence
- [ ] context freshness proof shows a versioned update
- [ ] sixth-spec bundle includes schema, insight summary, and trace
